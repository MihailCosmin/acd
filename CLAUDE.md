# acd

## Tasks

The tasks are in `tasklist.json` in the repository root. It is the only task list: there is no
TODO.md or DONE.md. The order of the file is the priority; the next task is the first one not done.
Check it with `& $env:WORKBENCH_CLI tasklist --repo acd` (format: `claude-usage-dashboard/app/tasklist.js`).

Background for the BREX checker tasks (evidence base, rule taxonomy, defects, work order) is in
`docs/brex_checker_rework.md`.
